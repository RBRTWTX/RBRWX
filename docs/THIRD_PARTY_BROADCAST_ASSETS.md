# Third-party Broadcast Assets

RBR WX Broadcast Assets uses established open-source/public-domain weather artwork rather than custom replacement drawings for the general weather icon library.

## Weather Icons

- Project: Weather Icons by Erik Flowers / original icon designs credited by the project to Lukas Bischoff.
- RBR WX integration: `@iconify/icons-wi` 1.2.3 individual icon data.
- Icons used: lightning, thermometer, strong-wind, rain, hurricane, thunderstorm, snow, day-sunny, snowflake-cold.
- Icon license: SIL Open Font License 1.1 (OFL-1.1).
- Upstream: https://github.com/erikflowers/weather-icons

## Material Design Icons

- Project: Material Design Icons by Pictogrammers.
- RBR WX integration: `@iconify/icons-mdi` 1.2.48 individual icon data.
- Icons used: radar, satellite-variant, map-marker.
- License: Apache License 2.0.
- Upstream: https://pictogrammers.com/library/mdi/

## NWS front symbology

Cold, warm, stationary, and occluded-front assets use the standard U.S. National Weather Service meteorological front symbology. The NWS weather-front reference is a U.S. federal-government work identified as public domain.

Reference: https://commons.wikimedia.org/wiki/File:NWS_weather_fronts.svg

## RBR WX alert boxes

The Alert / Warning / Watch / Advisory boxes retain the RBR WX/NEX GEN-style alert-box treatment because this was the accepted alert graphic behavior. They are not represented as third-party weather glyphs.
